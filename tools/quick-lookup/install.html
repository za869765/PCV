⚡ 快速掛號 書籤 v1.3

安裝方法一（拖曳）：先按 Ctrl＋Shift＋B 顯示書籤列，再把下面的按鈕用滑鼠按住、拖到書籤列放開（不是點它）。

⚡ 快速掛號

⚠ 這裡是安裝頁，點按鈕不會有作用。請把按鈕拖到書籤列，之後在要用的網頁上點書籤列上的書籤。

安裝方法二（拖不上去時）： → 在書籤列空白處按右鍵 →「新增網頁」→ 名稱填「快速掛號」、網址按 Ctrl＋V 貼上 → 儲存。

裝好後書籤列會出現「⚡ 快速掛號」（書籤列太滿時在最右邊的 » 裡）。

使用：
  1. 登入臺南市流感疫苗預約平台 → 進入「報到作業」→ 選好日期與場次。
  2. 點書籤列上的「⚡ 快速掛號」，右上角出現面板。
  3. 點選類別（Flu／XFG…，會保留，連續掛同類不用重選）。
  4. 輸入身分證按 Enter：未掛 → 自動打開「現場掛號」並填好身分證＋類別，檢查後由你按確認；已掛 → 顯示已掛類別與報到狀態。
  5. NIIS 接力：「💉 NIIS 最近接種」書籤換人時會自動把身分證放進剪貼簿；打開平台的「現場掛號」，在身分證欄按 Ctrl+V 即可（面板輸入框按 Ctrl+V 也行）。面板要保持開著（可按－縮小）。
  6. 防掛錯人：現場掛號身分證欄填好時（打字／掃描／貼上皆可），會跟 NIIS 畫面上的人比對：同一人 → 視窗上方綠色「✅ 與 NIIS 同一人」；不同人 → 全螢幕紅色警告並標出不一樣的字。第一次 Chrome 會問「查看剪貼簿」，請按允許。
  7. 再點一次書籤＝關閉面板。
安全說明：不會自行送出任何掛號／報到／退掛（只幫忙填好平台的現場掛號視窗，送出由你按）；不讀取或保存帳號密碼；不自行呼叫平台 API；只在現場掛號視窗填身分證時讀剪貼簿比對 NIIS 身分證（不保存）；不連線外部網站；不保存民眾資料（關閉即清除）；全部程式碼都在書籤內，可由資訊人員檢視 quick-lookup.js。
